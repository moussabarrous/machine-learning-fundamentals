# Machine Learning Fundamentals

A curated set of notebooks that show hands-on implementation and preprocessing work.

## Included notebooks

### `linear_regression_from_scratch.ipynb`
Multivariable linear regression implemented with NumPy, including z-score normalization, cost, gradients, gradient descent, convergence plots, and prediction-error analysis.

### `l2_regularization_from_scratch.ipynb`
L2-regularized linear/logistic cost and gradient functions implemented with NumPy, plus a reusable gradient-descent routine.

### `handling_missing_values.ipynb`
Missing-data exploration and mean/median/mode imputation using the Titanic dataset.

## Why these notebooks are grouped together

These are focused learning implementations rather than full standalone applied projects. Grouping them keeps the GitHub profile clean while still showing the underlying ML fundamentals.

## Run locally

```bash
pip install -r requirements.txt
jupyter notebook
```

## Portfolio policy

Only selected, cleaned notebooks are included here. Duplicate drafts and notebooks that still depend on private Google Drive paths or course helper files are intentionally left out until they can be made reproducible.
